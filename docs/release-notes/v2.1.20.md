## Chat On Steroids 2.1.20

This release focuses on the intermittent stalls where a long-running ChatGPT task could leave its next Goal or queued after-turn message waiting until the tab was manually refreshed or Chat On Steroids was restarted.

When the exact ChatGPT document still answers the companion's fenced health checks, CoS now treats the first two uncollected pickup watchdogs as soft recovery: it keeps the current page, confirms that its route/question/turn did not change, and immediately offers the already-durable input again in the same maintenance pass. This avoids turning a responsive but temporarily busy large conversation into a multi-minute reload.

If the same pickup is still not collected on the third watchdog attempt, CoS performs one real reload to reset page/content-script state. Later retries return to the soft path instead of reloading the same conversation every fifteen minutes for the remainder of the twelve-hour watch. Pages that are genuinely unavailable, discarded, frozen or non-responsive still use the existing hard reload/reopen recovery path.

The app and Chrome companion are both version 2.1.20 and remain on bridge protocol 14. The new repair hint is optional and degrades safely with an older peer, so there is no wire-compatibility bump.

Personalized release packaging is now Windows x64 only. The release contains the Windows x64 installer, the matching standalone Chrome extension and SHA-256 checksums; macOS, Linux, Windows ARM64 and native-source release artifacts are no longer produced.
