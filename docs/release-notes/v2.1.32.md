## 2.1.32 — Upstream 2.1.26 with Windows fork safeguards

Integrates the published official 2.1.22–2.1.26 changes on top of fork 2.1.31.

### Improved

- Reliable first-message receipts and live narration, exact selected-model confirmation, deeper React tree discovery, and visible-chat-only recording.
- Goal/Loop/Continue and Compact & Resume recover interrupted streams, preserve questions and answers, retire stale automatic drafts, and avoid needless reloads during resumed work.
- Native structured Core mentions for managed sends, with a preference for ordinary messages. Manual sends retain the fork's exact unchanged-draft native-send fallback.
- Follow new output, saved window placement, default model and reasoning for new chats, OpenRouter model search, worker health, skill revisions, and optional sleeping-worker runtime cleanup (off by default).
- Russian and Vietnamese, extension language synchronization and preference restoration, clearer settings and connection status, and per-round timeline summaries.
- Windows WSL approved folders, own-window desktop exclusion, execution-session continuity, connector refresh improvements, and published dependency updates.

### Fork safeguards

- Fork-only updater and extension URLs; Windows x64-only stable releases. App and extension share 2.1.32; bridge protocol remains 14.
- Host-process and bridge-port protections, runtime markers, conversation-scoped recovery, Temporary Chat proof/cleanup and promotion retention, durable Goal/session ownership, and extension build stamps are preserved.
- Automatic canary publishing is excluded. Published-release verification checks this fork's four payloads plus SHA256SUMS.txt, including the double-click updater.
- The PowerShell updater targets 2.1.32, verifies SHA-256 and leaves config.json, secrets.bin, sessions and other user data intact. Variable interpolation before a colon uses braces.

Official commit history and authorship are retained through the upstream release merge. Changes after official v2.1.26 are deferred; see docs/worklogs/upstream-2.1.26-integration.md for the scope and validation record.
