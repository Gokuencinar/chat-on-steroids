## Chat On Steroids 2.1.23

This release tightens browser lifecycle decisions around interrupted conversations and ChatGPT Temporary Chats.

An interrupted or failed latest turn can no longer become eligible for automatic browser reuse or closure merely because an older turn in the same conversation has a successful final answer. CoS now requires the latest durable turn outcome itself to be completed before treating the page as settled. Existing live-generation, draft, ownership and activity checks remain in force.

Temporary Chat state is now recorded only from positive page-model evidence on the exact current ChatGPT document. The companion reports whether the bound conversation is positively observed as temporary or regular; unknown or stale state grants no deletion authority. If ChatGPT later proves that a Temporary Chat became a regular saved chat, CoS clears the temporary marker and retains the local session normally.

Page-proven Temporary Chats are protected from automatic tab cleanup. When the user deliberately closes or leaves the final browser view of a still-temporary single-chat session, CoS removes that local recording so temporary conversations do not linger indefinitely in CoS after disappearing from ChatGPT. Multi-chat sessions and ambiguous/unknown ownership remain fail-closed and are not deleted by this path.

Regression coverage verifies exact-document temporary-state reporting, temporary-to-regular conversion, deletion only after the final deliberate browser departure, and the interrupted-turn case where an older successful final previously made a broken current page appear reusable.

The app and Chrome companion are both version 2.1.23 and remain on bridge protocol 14. This personalized release continues to publish only Windows x64: the Windows installer, matching standalone Chrome extension and SHA-256 checksums.
