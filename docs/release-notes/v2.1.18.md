## Chat On Steroids 2.1.18

This release folds a focused set of upstream improvements into the personalized Gokuencinar fork without taking the much larger experimental feature pack wholesale. Compact & Resume now has stronger recovery continuity, workers stalled at the context ceiling are preserved, and Goal/Loop or other automatic continuation can optionally wait for the current chat's own sub-agents. The handoff prompt is editable while its protocol wrapper remains fixed, and managed follow-up turns can reattach the Core connector and recover that enrollment after restart.

The desktop UI now marks completed background chats that have not yet been seen, renderer and browser-companion localization coverage is broader, and command execution can be constrained with optional allowlist or denylist policies. Project Files also gains a Git Changes view with working-tree status, per-file diff review and an agent-review action. Windows command recovery also recognizes Spanish-localized PowerShell parser diagnostics so syntax failures receive the same targeted guidance as English installations.

The personalized 2.1.17 hardening remains in place: ChatGPT plugin-refresh reminders are keyed to published connector schema changes, browser-extension compatibility is governed by bridge protocol 14 rather than semver ordering, and update/release links continue to use `Gokuencinar/chat-on-steroids`.

The GitHub Skills enhancements from upstream PR #345 are intentionally not included in 2.1.18. They were tested as an isolated port but are coupled to the broader workspace/composer redesign in that feature pack, so the existing Skills implementation remains unchanged for this release.

Because the companion extension itself changed substantially in this release, update/reload the browser extension to the matching 2.1.18 package after installing the app.
