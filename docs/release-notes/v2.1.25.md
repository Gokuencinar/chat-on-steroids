## Chat On Steroids 2.1.25 — Confirm first messages in new chats

This release fixes a duplicate pending instruction when starting a new ChatGPT conversation from CoS.

ChatGPT's newer composer can store app-inserted text with Markdown escapes. CoS now checks the normalized form as well as the original text when confirming the first message in a new chat. When ChatGPT has already accepted the instruction, CoS can retire its pending delivery instead of leaving a second, unsent copy in the app. The acknowledgement remains tied to the exact message and browser document, so this does not authorize another send.

The app and Chrome companion are both version 2.1.25 and remain on bridge protocol 14. This personalized release continues to publish only Windows x64: the Windows installer, matching standalone Chrome extension and SHA-256 checksums.
