## 2.1.41 — Official upstream 2.1.35 with Windows dictation and nine immersive styles

**Windows x64 release candidate for the Gokuencinar fork. Not yet published.**

### Highlights

- **Official v2.1.35 integrated.** New local projects can create their own ChatGPT Project and retry creation if necessary; background ChatGPT tabs can be grouped in your existing browser; worker Git worktrees isolate parallel changes when deliberately enabled (off by default). Existing projects are not migrated automatically.
- **More reliable long-running work.** Fixes for GPT-6 interim text order, history rate-limit backoff, messages joining live turns, orphaned in-progress timelines, missing file-path guidance, tool-owner attribution with strict settings, multiline formulas, and safer worker creation.

- **Dictate into the composer.** Use the microphone beside the message box to turn speech into editable text through the native Windows speech recognizer. Partial results appear as you speak; final words remain in the draft. **Dictation never sends a message automatically** — press Send when you are satisfied.
- **Stay in control of the microphone.** Start, stop or cancel dictation; editing the draft, leaving its chat or switching the composer retires the active recognition session. The UI reports microphone availability, errors and the current listening state. Windows speech recognition and its microphone permission must be available on the computer; it does not provide a live ChatGPT voice conversation.
- **Microphone shutdown safety.** Quitting CoS kills the speech helper immediately; if the app crashes or is forcibly terminated, its PowerShell recognizer detects the missing parent PID and releases the microphone. Both shutdown paths have focused tests without touching the actual audio device.
- **Messages reach active answers.** From official upstream 2.1.32 (e3596a7b), direct messages can reach the currently running ChatGPT answer while tools continue, with stronger delivery ownership and no duplicate send.
- **More dependable long sessions.** Stop remains stopped after late work, stale old turns do not trigger recovery, and the tunnel briefly holds messages for existing chats after restart until their route is ready.
- **A clearer timeline and tools.** ChatGPT choice prompts appear as read-only cards; plugin tool errors no longer unnecessarily disconnect a working plugin; confirmed connector refreshes, token usage and translated Skills descriptions are more accurate.
- **Nine immersive looks retained.** Classic, Cyberpunk, Gamer, Futuristic, Windows 95, Retro Terminal, Synthwave, Midnight OLED and Solar retain their live previews, adjustable light/dark colors and accessibility support.
- **Saved summaries and clearer waiting messages.** Official 2.1.33 (1c1a90d8) lets you restart from a completed Compact & Resume summary and tells you why an outgoing message is waiting.
- **Quieter and more reliable work.** Background chats follow your selection, idle ChatGPT pages use less CPU, history rate-limit retries behave better, and a confirmed missed Send can be retried once.
- **Windows and plugin fixes.** Terminal shutdown is safer, installation permission errors are explained, local plugins have a longer startup window, and Markdown export preserves Unicode filenames.
- **Official 2.1.34 improvements.** Goal and Loop can follow up on ChatGPT plans without a model picker. Compact & Resume succeeds more reliably in ChatGPT Projects, background chat windows survive extension reloads, and command results carry clearer notes about duplicate jobs or wrong connectors.
- **Connector renames.** Additional fixes from upstream `main` recognize the Core, Desktop and Plugins connectors by application ID confirmed by this installation, so changing a connector's display name does not silently break pairing.
- **Bridge recovery on Windows.** Auto connection now tries two additional five-port ranges when Hyper-V, WSL2 or Docker reserves 8765–8769. The Chrome extension's discovery and permissions follow the same exact port list. Explicit port preferences remain unchanged (upstream #1315).
- **Safer connector identity from the first turn.** The companion learns this installation's app ID from the response stream even when a new chat shows no tool rows, and a fresh tab bootstrap mentions the Core belonging to this computer instead of another computer sharing the ChatGPT account (upstream #1306 and #1307).
- **Correct message placement and deleted chats.** Messages sent while ChatGPT is already answering retain their proper place in the recorded timeline; when ChatGPT reports a deleted conversation, CoS fails its outstanding messages with a clear reason rather than leaving them waiting (upstream #1304 and #1311).
- **Cyberpunk attachments restored.** Removed the compositor clip that hid the top of the attachment menu; all nine appearances now have automated Electron hit-tests for their attachment options, with Retro and the other styles unchanged.

### Compatibility and distribution

- This fork integrates the **actual official v2.1.35 release commit 07d60918**, including previously selected #1304, #1306, #1307, #1311 and #1315 changes, while retaining its independent **2.1.41** application and extension version. The local historical tag v2.1.35 denotes an older fork build and must not be mistaken for the official tag.
- App and bundled extension are both **2.1.41**; the extension must match the installed app. Bridge protocol remains **14**, and existing configuration, conversations and appearance choices are retained.
- The release remains **Windows x64 only**. Updater, extension downloads and signed-off release checks use Gokuencinar/chat-on-steroids, with exact-tag selection and SHA-256 verification. The public release must not be claimed until the tag, assets and verification workflow have passed.
- The double-click CMD updater, installer and real-machine microphone behavior require final release validation; this candidate does not imply those checks have passed.
