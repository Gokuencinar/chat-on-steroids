## 2.1.38 — Official 2.1.29 and upstream follow-up improvements

This release brings the official 2.1.29 release and selected follow-up changes from the official repository's `main` through 2026-10-07 into the Windows fork.

### Added

- Pin chats, manage chats and projects from a shared row menu, and copy chat links.
- Search all chats from Ctrl+K, jump to matching messages, and find settings by name.
- Show when ChatGPT is waiting for a tool approval and when the browser connection is lost; approval always remains the user's decision.
- Recover long runs and Compact & Resume handoffs more reliably, including expired stream caches, closed chats, and one-notch scrolling.
- Add a What's New panel, a View menu for pets and the built-in browser, and bounded browser recovery.
- Improve project-entry and worker-revival diagnostics, config backup handling, and continuation ownership.

### Preserved from the fork

- Cyberpunk styling, native file-attachment handling and Core-send protections.
- Windows x64-only packaging, bridge protocol 14, and the fork-pinned updater's 403/429 fallback with SHA-256 verification.
- The standalone PowerShell updater defaults to 2.1.38 and accepts an optional exact version argument.

Windows x64 installer only. The release workflow builds the installer and extension from this tag, then verifies the published checksums and extension package.
