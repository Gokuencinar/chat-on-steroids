## 2.1.28 Core mention attachment hotfix

This hotfix restores automatic structured attachment of **Chat On Steroids Core** to managed manual follow-up messages.

### Fixed

- ChatGPT's current `@` menu is now detected through its `data-mention-list-scroll-area` composer overlay.
- Connector rows whose name and description are concatenated by the current ChatGPT DOM are matched safely through an exact descendant label.
- The existing fail-closed behavior remains intact: if the exact structured Core token cannot be proved, the draft is preserved and is not sent.

### Validation

- Added regression coverage using the current ChatGPT connector-menu shape.
- Added coverage for the current structured `app-mention-*` token generated after selecting Core.

The app and extension are versioned together at 2.1.28.
