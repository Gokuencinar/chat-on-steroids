## CoS 2.1.45 — public ECC Skills and appearance updater

- The customized fork includes the nine immersive appearance presets (Classic,
  Cyberpunk, Gamer, Futuristic, Windows 95, Terminal, Synthwave, Midnight OLED
  and Solar). Choose the desired style in **Settings → Appearance**; it does not
  replace another computer's current appearance on upgrade.
- Release resources now contain the complete **25 SHA-vetted ECC 2.2.3 Skills**
  and the **eight CoS workflows**, plus the separate maintained `/ecc-all`
  contextual orchestrator (34 optional managed Skills in total).
- `Actualizar-CoS-ECC-Skills-Apariencias-2.1.45.cmd` verifies a local build
  before upgrading, backs up the existing installation and **asks explicitly**
  whether to import missing ECC Skills afterward. `/skills-only` can be used
  later without reinstalling; `/check` and `/build-only` do not import.
- The downloadable `Actualizar-ChatOnSteroids.cmd` also prompts to import ECC
  Skills after a verified GitHub installer update while CoS remains stopped;
  existing installations can opt in later. It launches CoS only afterward.
- The importer validates the manifest, package layout and SHA-256 digests,
  preflights the 64-Skill cap, never overwrites existing managed/customized
  Skills, refuses to run while CoS is open and does not copy credentials,
  sessions, plugins, tunnel settings or personal profile archives.
- Source checkouts and CI packaging reproduce the exact 34 files deterministically
  via `node scripts/generate-ecc-install-resources.mjs --check`.

The original ECC GitHub project is MIT licensed (Affaan Mustafa). Only reviewed
resources are distributed; no Claude hooks, external runners or extra tool
permissions are installed. Skills do not activate by merely installing CoS.

## Build/update from this branch (Windows x64)

Requires Git, Node/npm and existing approved native packaging dependencies.
Run `Actualizar-CoS-ECC-Skills-Apariencias-2.1.45.cmd /build-only` to build
without installing, then `/check` to verify the exact candidate. Close CoS
voluntarily from the system tray before running the CMD with no arguments or
`/install-built`. The updater never force-kills CoS or its tunnels.

The private `CoS-Perfil-Portable-2026-10-17.zip` profile is **not** published:
its 39 personal Skills and private appearance preferences are local user data,
not public release inputs.
