## Chat On Steroids 2.1.19

This release synchronizes the desktop app and Chrome companion after the 2.1.18 stability release. Both now ship as 2.1.19 while retaining bridge protocol 14, so the compatibility contract is unchanged but the installed companion receives the latest DOM, Fiber, prompt-frame and recovery fixes.

Browser recovery is less destructive on large or long-running chats. A silent chat that still answers the companion's exact-page health check is resumed in place instead of being reloaded, while genuinely unresponsive, discarded or frozen pages retain the existing reload path. Repairs offered to a page that no longer exists are now bounded, cancelled unsent rescue turns can be filed again when the same turn later stalls, and Compact & Resume falls back to opening its replacement locally when the browser never claims the placement.

Session durability and recovery are also strengthened. Transient filesystem failures are no longer interpreted as empty session history, session summaries are flushed before their atomic publish rename, and a working oversized chat can refile an automatic compaction after a previous refusal instead of remaining permanently blocked.

The Chrome companion now recognizes translated Stop controls from their stable icon shape, reads prompt transport frames after ChatGPT's Markdown escaping, and can prove Temporary Chat mode from the mounted React state when the page exposes it. Temporary Chat detection is therefore more resilient to localized or changing ChatGPT layout, although the separate post-navigation decision-identity edge case remains intentionally outside this release.

PowerShell recovery hints now recognize localized ScriptBlock parse failures more broadly, and validation no longer misreports missing-ripgrep environments as shell regressions.

Release packaging also refreshes the pinned OpenAI tunnel client to v0.0.15. All six supported OS/CPU archives remain checksum-pinned, and the publish workflow still refuses to ship if that pin is not OpenAI's current stable tunnel-client release.

After installing 2.1.19, reload the unpacked Chrome extension from the stable Chat On Steroids extension folder so Chrome activates the matching 2.1.19 companion code.
