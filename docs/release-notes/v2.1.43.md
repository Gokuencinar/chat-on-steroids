## 2.1.43 — More ECC skills and clearer ChatGPT dictation

**Unpublished candidate of the personalized Gokuencinar fork; Windows x64.**

### New and improved

- **ECC v2.2.3 Skills expansion.** The reviewed catalog of source-pinned, standalone ECC skills is expanded to cover more engineering work. Imports remain individually selected, bounded and subject to the existing approved roots and live tool permissions. Skills provide instructions, not additional tools, operating-system permissions, automatic hooks or services. Each source and imported byte sequence has SHA-256 provenance, with corresponding import tests.
- **ChatGPT microphone in the signed-in browser.** A new explicit **ChatGPT (browser)** selector opens the selected ChatGPT conversation (or the normal ChatGPT page for a new chat) using CoS's existing browser. Use ChatGPT's own microphone there, with its normal user gesture and OS/browser permissions. The built-in CoS browser grants only audio permission for the exact `https://chatgpt.com` origin in its isolated browser partition, not for arbitrary websites or cameras. This uses the signed-in ChatGPT product, not a private transcription API or the user's CoS API key. Audio and draft text stay in the ChatGPT browser composer until the user sends them; they are **not automatically copied into CoS's unsent draft**.
- **Actionable OpenAI API errors.** The optional, separately billed cloud transcription mode now distinguishes exhausted API credits, project/organization spending limits, organization usage limits and temporary rate limiting based on documented HTTP 429 error codes. It never displays raw server error text or secrets; a 429 quota response is not retried blindly.
- **Windows local speech remains available.** The existing Windows System.Speech provider still fills CoS's unsent draft directly and requires no OpenAI API credits, subject to installed recognition languages and Windows microphone access.

### Compatibility and remaining limits

- App, lockfile, bundled extension and What's New use fork version **2.1.43** (2.1.42 → 2.1.43); bridge protocol is unchanged. Repository-specific ECC features, themes, learning opt-in, agent tools and customized update target remain.
- OpenAI ChatGPT subscription and OpenAI API billing are separate. The ChatGPT browser microphone cannot be relayed as an undocumented third-party speech API. The browser user interface and permission flow require manual validation on the installed machine.
- No real microphone or paid API request is part of the automated suite. Builds, Skills import and browser handoffs require their own verification before installation or public release; packaging is not publication.
