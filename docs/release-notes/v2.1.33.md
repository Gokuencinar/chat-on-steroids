## 2.1.33 — Cyberpunk gaming appearance

- New optional Cyberpunk preset in Settings → Appearance with intense cyan/magenta neon, dark blue surfaces, a static grid, futuristic panel borders and an illuminated composer.
- Colors, font and text size remain editable. Selection persists across restarts; Reset restores the classic appearance. Existing configurations and concurrent saves from older windows remain compatible.
- Decorative effects use local CSS with no external images/fonts or continuous animations.
- App and extension share version 2.1.33; bridge protocol remains 14. Windows x64-only release and all fork safeguards are preserved.

Validation before publication: production build, typecheck, 131 focused tests, 6,902 full-suite tests (48 skipped), and all 38 real-Electron UI checks passed. Cyberpunk was additionally checked at narrow widths and up to 150% zoom; message reactions passed on retry. Screenshots and UI checks use isolated fixtures.

The updater verifies the published SHA-256 and preserves configuration, encrypted credentials, sessions and plugins.
