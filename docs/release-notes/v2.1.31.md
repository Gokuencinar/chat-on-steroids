## 2.1.31 — Upstream 2.1.21 sync with fork safeguards preserved

This release brings the official 2.1.21 feature and reliability update into the customized fork while keeping the fork-specific Windows updater, release routing and Core-attachment safeguards.

### Integrated from upstream

- Korean localization.
- Redesigned Normal / Goal / Loop composer, separate Plan control, richer context meter, full model picker and smoother effort controls.
- Live activity and elapsed-time lines while ChatGPT works.
- Copy/export for answers and Markdown export for the whole chat.
- Source pills, recap titles, lighter tool-call presentation and smoother/reorderable side and bottom panels.
- Optional local control API for trusted tools on this computer, disabled by default.
- Goal, Loop and Compact & resume reliability fixes for long answers, long thinking, composer redraws and recovery delivery.
- Stronger browser ownership when the same account is open in more than one browser.
- Saved GPT-6 Pro/model refresh fixes and language-independent Pro detection.
- Chat-view, terminal, workspace, legacy-chat-title and restricted-extension-access fixes.
- A new **Actualizar-ChatOnSteroids.cmd** release asset can be run with a double click on Windows. It checks the fork's latest release, verifies the installer against the published SHA-256, updates the app only when needed, then lets the installed app synchronize and safely reload its bundled extension when Chrome is idle.

### Fork behavior retained

- Windows x64-only packaging and fork-only update/release URLs.
- Host-process and bridge-port protections.
- Per-conversation recovery and Temporary Chat handling.
- Connector refresh/recovery customizations.
- The 2.1.28–2.1.30 manual Core-attachment fixes, including safe native-send fallback when structured Core attachment cannot be proven without changing the draft.
- Existing config.json, encrypted secrets, sessions and plugin data are left in the per-user data directory; the updater never deletes or replaces that directory.
