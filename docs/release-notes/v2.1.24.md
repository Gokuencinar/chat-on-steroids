## Chat On Steroids 2.1.24 — Reliable ChatGPT stream recovery

This release improves recovery when ChatGPT loses the connection during a long response.

CoS now recognizes ChatGPT's “Resume stream unavailable” and full network-error messages as transport failures, so its existing bounded recovery can respond to those errors instead of waiting for the ordinary stalled-turn timeout.

Before blind or unattributed recovery reloads a browser tab, the companion checks whether that exact page is still streaming. If generation is active, it leaves the tab alone; reloading mid-response can itself interrupt the answer and make ChatGPT report “Resume stream unavailable”.

The app and Chrome companion are both version 2.1.24 and remain on bridge protocol 14. This personalized release continues to publish only Windows x64: the Windows installer, matching standalone Chrome extension and SHA-256 checksums.
