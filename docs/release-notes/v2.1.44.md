## 2.1.44 — Complete ECC All Workflows installer

Local Windows x64 candidate of the personalized Gokuencinar CoS fork. This follows 2.1.43 and retains its microphone options, native ECC learning, reviewed 25 ECC source Skills and eight CoS-adapted workflows.

### ECC All Workflows

The ECC Skills page offers one card with two independent actions:

- **Install 8 workflows:** preserves the previous ECC core pack behavior, installing only eight CoS-native workflow Skills.
- **Install complete ECC pack (33 Skills):** asks for confirmation and imports the eight workflows plus all 25 ECC v2.2.3 source-SHA-pinned reviewed Skills. Displays missing entries and available capacity (64 managed Skills maximum) before beginning.

The complete-pack import verifies every bundled ECC package's SHA-256 and rechecks package contents and hashes within the serialized Skills library owner. A preflight rejects insufficient capacity, conflicting orphan folders, duplicate IDs and changed packages **before creating any new Skills**. Existing Skills (including customized versions with the same ID) remain untouched. Repeated installs are idempotent; simultaneous basic/complete installs share the existing library serialization. If an unexpected I/O fault interrupts the batch after preflight, previously completed imports remain rather than being destructively rolled back, and retry picks up missing entries.

No Claude lifecycle hooks, background observers, network packages or additional tool permissions are installed by choosing either option. As previously, workflows are instructions that operate only through CoS's available tools. The actual import still requires the user's active create permission.

Installer/runtime verification and test results must be reported separately; no installed client is changed merely by preparing this source release.
