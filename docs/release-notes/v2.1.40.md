## 2.1.40 — New appearance styles

CoS now has nine styles to choose from in Appearance: Classic, Cyberpunk, Gamer, Futuristic, Windows 95, Retro Terminal, Synthwave, Midnight OLED and Solar.

- Cyberpunk has brighter pink and cyan neon accents.
- Gamer brings dark green tones; Futuristic uses cool blues and glass effects.
- Windows 95 adds retro square controls and a blue title bar. Retro Terminal adds a green phosphor look.
- Synthwave, Midnight OLED and Solar offer more color choices.
- Each style comes with its own editable light and dark colors, font choices and a preview. Selection and custom changes stay saved.
- Style names and descriptions are translated into all 12 languages.

This release builds on 2.1.39, keeping GPT-6 support, timeline rounds, the current worker controls and the existing security and recovery fixes. Existing appearance preferences remain compatible. Windows x64 only; the app and extension are both 2.1.40 and the bridge protocol remains 14.
