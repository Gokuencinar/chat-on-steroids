## 2.1.30 Manual sends can never be trapped by Core auto-attach

This hotfix changes the Core auto-attachment boundary so a connector-mention failure cannot make ChatGPT unusable while CoS is open.

### Fixed

- Manual web sends and desktop-app drafts no longer remain trapped just because the structured **Chat On Steroids Core** mention could not be attached.
- When auto-attach fails, CoS verifies that the same conversation and composer are still active, ChatGPT is not generating, the native Send button is ready, and the original draft plus attachments are unchanged. If all of those proofs hold, it sends the original message normally without Core.
- If the attachment attempt altered the draft, ChatGPT became busy, the route changed, or Send stopped being ready, CoS still fails closed to avoid sending altered or stale content.

### Validation

- Regression coverage now proves that an unprovable Core mention falls back to exactly one native send when the draft is unchanged.
- A second regression proves that CoS still blocks when a failed attachment leaves partial Core mention text in the draft.

The app and extension are versioned together at 2.1.30.
