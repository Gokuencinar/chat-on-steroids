## Chat On Steroids 2.1.21

This release improves reliability when several ChatGPT conversations are active at the same time.

Recovery and queued-delivery boundaries now track in-flight browser observation writes per conversation. A slow history write in one chat no longer blocks a valid repair claim, Goal activation or silence-input filing in another chat. Operations that truly require the whole recorder to be quiet, such as family-wide orphan cleanup, keep the existing conservative aggregate guard.

Session ownership lookup is also safer during temporary filesystem failures. If CoS cannot complete the metadata read needed to decide which local session owns a conversation, it now leaves the browser observations retryable and returns an error instead of treating the conversation as new. This prevents a transient read problem from splitting one ChatGPT conversation across two local session histories.

Regression tests cover both same-chat and cross-chat observation fencing and verify that unreadable ownership metadata cannot create a replacement session directory.

The app and Chrome companion are both version 2.1.21 and remain on bridge protocol 14. This release continues the personalized Windows x64-only distribution: the published assets are the Windows x64 installer, the matching standalone Chrome extension and SHA-256 checksums.
