## 2.1.29 Manual Core attachment follows native composer readiness

This hotfix fixes a remaining case where a manual follow-up could be blocked with **“Chat On Steroids Core could not be attached to this message”** while CoS was open.

### Fixed

- The automatic Core attachment no longer treats CoS's internal recorder `generating` flag as authority for whether a manual user send is allowed.
- ChatGPT's own live composer state remains authoritative: the same editor and conversation must still be mounted, the page must not actually be generating, the structured Core token must be proven, and the native Send button must be ready.
- This avoids a race where the recorder is still closing the previous turn while ChatGPT has already returned to Send and the user legitimately submits the next message.

### Validation

- Added a content-script regression that opens a recorded generation, lets the native page return to Send before the recorder's quiet-window closes, and verifies that Core is still attached and the manual send proceeds once.

The app and extension are versioned together at 2.1.29.
