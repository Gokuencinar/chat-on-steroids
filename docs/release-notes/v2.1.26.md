## 2.1.26 Official sync and fork reliability

This release brings the customized fork onto the current official Chat On Steroids development line through PR #552, including the newer workspace panels, Skills library, Usage improvements, current Plugins setup flow, extension self-update, model fallbacks and Goal/Loop reliability work.

The fork's own reliability behavior remains in place and has been adapted to the newer architecture:

- CoS refuses commands that would terminate its own host process or the processes owning its protected bridge ports.
- Browser repair and observation-write gates are scoped to the exact conversation, so activity in one chat does not unnecessarily block another.
- A silent but responsive ChatGPT page is resumed in place instead of being reloaded.
- Temporary Chat recordings are protected while their page is open and removed locally when the final manually closed view proves the chat was temporary.
- Chat On Steroids Core is automatically attached through ChatGPT's native structured mention for managed manual follow-ups when its installed identity is known.
- An unresolved first-time plugin enrollment gets one fresh request after restarting CoS, with Core enrollment prioritized before the other surfaces.

The fork continues to publish the Windows x64 installer and matching companion extension from `Gokuencinar/chat-on-steroids`.
