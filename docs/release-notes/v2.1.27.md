## 2.1.27 Upstream 2.1.20 sync with fork reliability preserved

This fork release integrates all official changes through upstream 2.1.20 while preserving the fork-specific reliability and Windows release behavior from 2.1.26.

### Upstream improvements included

- Recommended Skills install correctly again and keep descriptions that contain colons.
- The browser extension pairs and reconnects automatically after updates or reloads.
- Review retains larger edits more reliably and explains when a diff cannot be kept.
- Project chats recover their real title and worker queue reporting is more accurate.
- OpenRouter API keys are cleaned of invisible copied characters before use.
- ChatGPT content-reference replies resolve to their real content for the UI, Goal and worker reports.
- Unknown ChatGPT directives are rendered as ChatGPT content instead of raw directive syntax.

### Fork behavior preserved

- Windows x64-only release packaging and fork-only update URLs.
- Host-process protection and bridge-port safeguards.
- Per-conversation recovery and responsive silent-chat resume without destructive reloads.
- Temporary Chat recording/lifecycle semantics.
- Connector refresh rearm and structured Chat On Steroids Core attachment.
- Goal/Loop durability and session ownership hardening.

The app and extension are versioned together at 2.1.27.
