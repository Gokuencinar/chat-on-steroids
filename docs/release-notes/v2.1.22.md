## Chat On Steroids 2.1.22

This release focuses on recovery paths that could leave a healthy ChatGPT page or CoS session stuck even though the durable state was still safe to continue.

Compact & Resume now recovers a replacement page when its durable command redemption succeeded but the response back to the content script was lost before the first destination Send checkpoint. The retry is deliberately narrow: it stays on the same live document, command marker and opening identity, and it is allowed only before `destinationAttempt`. Existing no-replay fences remain authoritative after Send becomes ambiguous.

Temporary-planner completion is also more tolerant of a real ChatGPT remount pattern. If the exact accepted user row is still stamped by the immediately older Fiber scan while the terminal assistant is current, CoS can use the already-recorded Send receipt plus the exact submitted text to harvest the planner result. Missing, current-conflicting, wrong-ID and changed-text evidence still fail closed.

The browser companion now recognizes `ChatGPT stream recovery polling timed out` as a transport failure eligible for the existing recovery path. Explicit provider access limits such as `Too many requests` remain blocking, non-recoverable signals and do not create reload authority.

Connection setup now prevents two active CoS connector surfaces from sharing one OpenAI Secure Tunnel ID. Core, Desktop and Plugins expose different MCP catalogs, so each active surface must own a different request queue. New conflicting settings are rejected, while a legacy conflict leaves the lower-priority optional connector unpublished with a clear error instead of racing two consumers on one queue.

Two long-session accounting stalls are tightened as well. An ordinary browser message whose Send was already authorized but whose ACK never arrives stops blocking unrelated later work after five minutes without ever becoming replayable; an exact late receipt can still settle its retained tombstone. Separately, CoS now remembers the estimated token weight of the complete native payload it sent, so later page projection of only the authored portion does not make the context meter forget hidden setup/context text that ChatGPT still carries.

This release also incorporates eight upstream reliability fixes for successor opening, split request-ID evidence, localized Send discovery, longer silence windows above High reasoning, stale React `in_progress` state, shell turn identity, delivery over CoS-owned composer residue and selection of the nearest available reasoning effort when a previously saved effort disappears.

Regression coverage was added for the new recovery boundaries, tunnel-ID conflicts, late browser ACKs, full-payload context accounting and the new transport-error text. The app and Chrome companion are both version 2.1.22 and remain on bridge protocol 14.

This personalized release continues to publish only Windows x64: the Windows installer, matching standalone Chrome extension and SHA-256 checksums.
