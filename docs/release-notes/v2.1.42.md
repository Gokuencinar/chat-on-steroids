## 2.1.42 — Reliable recovery and safer OpenAI dictation

**Local Windows x64 candidate of the personalized Gokuencinar fork. Not published.**

### Highlights

- **Recovery after Windows sleep (#1420).** A delayed maintenance sweep grants active chats 90 seconds to reconnect when the computer resumes from suspension, instead of immediately treating their expired activity deadlines as silence. The punctual silence timer remains independently scheduled; the exact order of real timers after resume still merits Windows validation.
- **Safer OpenAI microphone capture.** Unexpected recording termination (for example, a disconnected microphone or revoked permission) discards buffered audio without uploading it. The UI discloses, before the first recording, that cloud audio is uploaded on Stop **or automatically at the 45-second recording limit**. A transcription never sends the ChatGPT message for you.
- **OpenAI IPC validation.** Cross-JavaScript-realm Uint8Array microphone bytes are accepted without allowing fake objects or untyped buffers. Destruction listeners are released when requests complete or fail.
- **Resilient image export (#1421).** An exclusive copy fallback saves images on file systems without hard-link support, without overwriting an existing file.
- **Updater reliability (#1419).** Failed periodic update checks retry at 1, 5, and 30 minutes, and downloads fail after 60 seconds without progress rather than timing out merely for being large.
- **Preserve UTF-8 BOM (#1423).** Code patches preserve the byte-order mark of PowerShell and other UTF-8 files.
- **All existing custom features remain.** The ECC learning/workspace/catalog, local/native and OpenAI dictation modes, nine appearances, custom projects, and the Gokuencinar update target are retained.

### Version and verification

- Follows **2.1.41 → 2.1.42** in the independent fork. `package.json`, `package-lock.json`, the native app and the bundled extension all use **2.1.42**. The bridge protocol is unchanged.
- This is a local build, **not** the official upstream version number or a public GitHub release. Its updater/extension URLs still target `Gokuencinar/chat-on-steroids`.
- Automated tests use simulated browser events/audio and mocked HTTP: they do **not** prove real microphone hardware, a paid OpenAI transcription, or actual Windows resume behavior.
- Use the local x64 updater after reviewing and saving current work. The CMD verifies the candidate, backs up the installed application, never force-quits running processes, and does not delete AppData/user settings. Do not treat a successful NSIS exit alone as proof: verify the installed payload hashes and relevant runtime behavior.
